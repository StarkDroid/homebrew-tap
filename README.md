# Homebrew tap for Bento terminal

```sh
brew install StarkDroid/tap/bento
```

Bento terminal is a full-screen terminal workspace for one project directory:
preview and edit files, review changes, run builds, open a shell, and run
coding agents beside the preview.

- Site: https://starkdroid.github.io/Bento-Terminal/
- Source: https://github.com/StarkDroid/Bento-Terminal
- Releases: https://github.com/StarkDroid/Bento-Terminal/releases
